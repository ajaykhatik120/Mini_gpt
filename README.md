# mini_gpt_from_scratch

A minimal project skeleton for building a small GPT-style model from scratch.

## Structure

- `tokenizer/` handles text-to-token conversion.
- `model/` contains the core model implementation.
- `training/` exposes a simple training entry point.
- `inference/` generates new text from a prompt.
- `visualization/` can be used for plotting training progress.
- `utils/` stores shared configuration helpers.

## Run

```bash
python main.py
```
